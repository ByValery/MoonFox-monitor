# MoonFox monitor

Локальная система мониторинга сайтов, серверов, компьютеров, роутеров и других сетевых устройств для Windows.

> Следит за системой, пока ты спишь.

![MoonFox monitor](assets/moonfox-logo.png)

**Текущая версия: 0.7.0**

## Возможности

- Проверка доступности сайтов и времени ответа.
- Типы сервисов для сайтов: обычный сайт, Jellyfin, Nextcloud, Home Assistant, Grafana и Prometheus с готовыми health endpoints.
- Ping- и TCP-проверка сетевых устройств.
- Проверка DNS и SSL-сертификатов сайтов.
- Проверка нескольких TCP-портов одного устройства.
- Ручная диагностика Ping, DNS, SSL, Traceroute и WHOIS/RDAP.
- Ручное сканирование частной локальной сети `/24` с отображением IP, имени, MAC-адреса и ping.
- Раздельные интервалы проверки сайтов и устройств.
- Графики в виде линий, столбцов и круговых диаграмм.
- Независимые графики с выбором конкретных сайтов или устройств.
- Настраиваемое количество строк на главной странице.
- Изменение порядка сайтов и устройств с синхронизацией порядка на графиках.
- Подтверждение проблемы после нескольких неудачных проверок.
- Журнал событий и история измерений.
- Уведомления через Telegram.
- Ответные команды Telegram-бота: `/status`, `/sites`, `/devices`, `/problems`, `/check`, `/help` (восстанавливаются после стабилизации SQLite-ядра).
- Импорт и экспорт конфигурации.
- Темы, цвета и масштаб интерфейса.
- Русский и английский языки интерфейса.

## Требования

- Windows 10 или Windows 11.
- Современный браузер.

В версии 0.7 программа использует новый SQLite backend. В комплект можно положить локальный Python в `runtime/python`, тогда установка Python в систему не нужна.
Дополнительные Python-пакеты не требуются.

## Запуск

1. Скачайте репозиторий или архив проекта.
2. Запустите `RUN.cmd`.
3. Откройте `http://127.0.0.1:8000/`, если браузер не открылся автоматически.

`RUN.cmd` сначала использует локальный `runtime/python/python.exe`. Если его нет, пробует системный Python.

При первом запуске программа самостоятельно создаст локальную базу `data/moonfox.db`.
Если рядом есть старая база `data/db.json`, данные будут автоматически перенесены в SQLite.

## Настройка

Все основные параметры изменяются во вкладке **Настройки**:

- интервалы и таймауты проверок;
- пороги предупреждений;
- порт веб-интерфейса;
- параметры Telegram;
- внешний вид.

После изменения порта перезапустите программу.

### Команды Telegram-бота

1. Укажите Telegram bot token и свой chat ID.
2. Включите **«Разрешить ответные команды бота»**.
3. Сохраните настройки.
4. Нажмите **«Проверить команды бота»**.

Бот отвечает только сохранённому chat ID. Команда `/check` запускает полную проверку сайтов и устройств.

## Хранение данных

Сайты, устройства, история, события и Telegram-данные хранятся локально:

```text
data/moonfox.db
data/db.json
data/db.backup.json
```

`data/moonfox.db` — основная база SQLite. `data/db.json` и `data/db.backup.json` оставлены для миграции и резерва.
Эти файлы исключены из Git, поскольку могут содержать адреса устройств, историю мониторинга и секретный токен Telegram.

## Структура проекта

```text
assets/            изображения и иконки
css/style.css      стили интерфейса
js/app.js          логика интерфейса
index.html         основная страница
moonfox_server.py  локальный HTTP-сервер и мониторинг (SQLite backend)
data/              локальная база данных и настройки (не в Git)
runtime/           портативный Python (опционально, не в Git)
RUN.cmd            запуск программы
```

## Безопасность

Программа предназначена для локального запуска и слушает адрес `127.0.0.1`. Не публикуйте файлы из папки `data` и не размещайте Telegram bot token в репозитории.

Сканирование сети ограничено частными IPv4-подсетями. Массовое сканирование публичных адресов запрещено программой.

Все запросы к `/api/*` проверяются по заголовкам `Origin`/`Referer`: сервер принимает только запросы со страницы самого MoonFox. Это защищает от CSRF — сценария, когда открытая в браузере сторонняя страница пытается втихую дёрнуть API (например, сбросить данные) от твоего имени. Если обращаешься к API напрямую (curl, скрипты), передавай заголовок `Referer` или `Origin` со значением `http://127.0.0.1:<порт>`, иначе сервер ответит `403`.
